# SERAPH Robotics

**Intelligence in motion. Engineered in Africa. Built for the world.**

A premium, responsive company website for SERAPH Robotics, built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Homepage: vision, Teach · Build · Deploy, solution highlights, Africa-first impact and partnership CTA.
- `/solutions` — Education, industrial/logistics, everyday/agriculture and safety/security offerings.
- `/about` — Mission, company story and values.
- `/impact` — Talent, local capability, deployment and global ambition.
- `/careers` — Team values and open-role placeholder.
- `/contact` — Partnership and general enquiry form.

Contact submissions currently display an accessible client-side confirmation; connect the form to a CRM or API endpoint before production. Images use remote Unsplash URLs as editorial placeholders; replace with approved company photography as it becomes available.
